# LightSearch Keyboard Shortcuts

## Global Shortcuts

| Shortcut | Action | Description |
|----------|--------|-------------|
| ⌘F | Focus Search | Jump to search field and start typing |
| ⌘K | Clear Search | Clear current search query and results |
| ⌘, | Preferences | Open settings window |
| ⌘Q | Quit | Quit LightSearch |

## Indexing

| Shortcut | Action | Description |
|----------|--------|-------------|
| ⌘⇧R | Rebuild Index | Perform full rebuild of photo index |
| ⌘⇧U | Update Index | Incrementally update index with new photos |

## Detail View (Photo Viewer)

| Shortcut | Action | Description |
|----------|--------|-------------|
| Esc | Close | Close detail view and return to results |
| ← | Previous Photo | Navigate to previous photo in results |
| → | Next Photo | Navigate to next photo in results |
| Space | Zoom In/Out | Toggle between fit and 100% zoom |
| ⌘+ | Zoom In | Zoom in by 25% |
| ⌘- | Zoom Out | Zoom out by 25% |
| ⌘0 | Reset Zoom | Reset zoom to fit window |
| ⌘R | Reveal in Finder | Show photo in Finder |

## Filter Panel

| Shortcut | Action | Description |
|----------|--------|-------------|
| ⌘⇧F | Toggle Filters | Show/hide filter sidebar |
| ⌘⌫ | Clear All Filters | Reset all active filters |

## Tips

- **Search as you type**: Search results update automatically as you type (300ms debounce)
- **Natural language**: Search using plain English descriptions like "golden hour sunset" or "portrait with shallow depth of field"
- **Combine filters**: Use semantic search with metadata filters for precise results
- **Score badges**: Green (85%+), Blue (75-84%), Orange (68-74%) indicate match quality

## Menu Bar

All keyboard shortcuts are also accessible via the menu bar:

- **File** → Standard file operations
- **Edit** → Standard editing operations
- **View** → Search and indexing shortcuts
- **Window** → Window management
- **Help** → Documentation and support

## Customization

Keyboard shortcuts can be customized in **System Settings → Keyboard → Keyboard Shortcuts → App Shortcuts** by adding LightSearch-specific overrides.
